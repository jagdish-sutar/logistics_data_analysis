# Week 1 — Strategic Planning and Data Exploration

**YuvaIntern | Logistics Data Analyst Intern**

This folder contains the Week 1 strategic planning deliverables for a logistics analytics project.

## Objective

Define a logistics analytics scenario, establish KPIs, identify a public data source, explain proposed data-science methods, and create a roadmap from data collection to operational recommendations.

## Contents

- `week1_strategy.ipynb` — documented Jupyter notebook
- `src/week1_strategy.py` — illustrative Python templates for KPI calculation, regression, and clustering
- `data/README.md` — data-source and raw-data guidance

## Proposed Dataset

Brazilian E-Commerce Public Dataset by Olist.

The Week 1 notebook is a planning exercise. It does not claim real-world logistics results.

## Proposed Methods

- KPI analysis
- Regression
- Clustering
- Optimization
- Exploratory data analysis

## Roadmap

Data Collection → Data Validation & Cleaning → Feature Engineering → EDA → KPI Measurement → Predictive Modeling → Clustering → Optimization → Operational Recommendations
