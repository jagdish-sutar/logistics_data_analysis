# Data

The Week 2 project uses the **Brazilian E-Commerce Public Dataset by Olist**.

The raw dataset is intentionally not included in this repository.

Expected raw file for the example preprocessing script:

```text
data/raw/olist_orders_dataset.csv
```

Additional Olist tables can be added when extending the project to item-level, seller-level, customer-level, or product-level analysis.

Keep raw data unchanged and store generated/processed files separately.
