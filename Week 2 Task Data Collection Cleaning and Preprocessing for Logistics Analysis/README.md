# Week 2 — Data Collection, Cleaning, and Preprocessing

This folder contains the Week 2 deliverables for the YuvaIntern Logistics Data Analyst Internship.

## Objective

Develop a reproducible preprocessing workflow for logistics analysis using the Brazilian E-Commerce Public Dataset by Olist.

## Contents

- `week2_data_preprocessing.ipynb` — Jupyter notebook documenting the preprocessing methodology and Python examples.
- `src/preprocess_logistics.py` — reusable Python preprocessing script.
- `data/README.md` — instructions for obtaining and storing the raw dataset.

## Workflow

1. Data collection and source documentation
2. Initial inspection
3. Missing-value assessment
4. Duplicate review
5. Timestamp parsing
6. Delivery feature engineering
7. Outlier investigation using IQR
8. Numerical standardization
9. Data-quality validation
10. Export of processed data

## Important

The raw Olist dataset is not included in this repository. Download it separately and place the CSV files under `data/raw/`.
