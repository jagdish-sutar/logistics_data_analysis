# Week 3 — Advanced Data Analysis and Visualization

**YuvaIntern | Logistics Data Analyst Intern**

This project demonstrates exploratory data analysis and visualization using a hypothetical logistics dataset of 500 shipment records.

## Dataset
The dataset contains Region, Transport Mode, Month, Shipment Volume, Distance, Delivery Time, Transport Cost, Delay Status, and Customer Satisfaction.

The dataset is synthetic and is included for reproducibility. It does not represent real operational data.

## Analysis
- Descriptive statistics and central tendency
- Delivery-time distribution
- Transport-cost comparison by mode
- Shipment-volume vs delivery-time relationship
- Regional delay analysis
- Correlation analysis
- Monthly delivery-time trends
- Operational observations and recommendations
