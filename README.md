# YuvaIntern — Logistics Data Analyst Internship

A four-week logistics data analytics project completed as part of the YuvaIntern Logistics Data Analyst Internship.

## Project Overview

This repository documents a progressive logistics analytics workflow:

**Week 1 → Strategic Planning**  
**Week 2 → Data Collection & Preprocessing**  
**Week 3 → Exploratory Data Analysis & Visualization**  
**Week 4 → Predictive Modeling & Optimization**

The project demonstrates how logistics data can be transformed from a strategic business problem into an analysis pipeline and then into predictive and optimization workflows.

## Dataset

The projects use a combination of publicly available and synthetic datasets.

- Week 1 and Week 2 use the Brazilian E-Commerce Public Dataset by Olist as the reference public dataset.
- Week 3 and Week 4 use hypothetical/synthetic logistics datasets created for educational analysis.
- Synthetic data and results are clearly identified and should not be interpreted as real operational performance.

Raw datasets are not included where they are unnecessary or too large. Dataset source and usage instructions are documented inside the relevant week folders.

## Learning Workflow

The internship project follows a progressive analytics workflow:

1. Define the logistics business problem and KPIs.
2. Identify data requirements and design a collection strategy.
3. Clean, transform and prepare the data.
4. Perform exploratory analysis and visualization.
5. Build predictive models and evaluate their performance.
6. Demonstrate how predictions can support logistics optimization.

## Repository Contents

Each weekly project contains its own README, notebook and supporting Python code. Where applicable, datasets, charts, model results and reports are also included.
