# Logistics Data Analysis & Predictive Modeling

An end-to-end **four-week logistics data analytics project** completed as part of the **YuvaIntern Logistics Data Analyst Internship**.

The project covers the complete analytics workflow — from business problem definition and data exploration to data preprocessing, exploratory analysis, visualization, predictive modeling, and logistics optimization.

---

## 📌 Project Overview

Logistics operations generate large volumes of data across orders, customers, products, delivery routes, costs, and operational performance.

This project explores how data analytics and machine learning can be used to:

* Understand logistics operations and business requirements
* Identify relevant operational KPIs
* Collect and structure logistics data
* Clean and preprocess raw datasets
* Perform exploratory data analysis
* Identify patterns and relationships within logistics data
* Create meaningful visualizations
* Build predictive machine learning models
* Explore approaches for logistics optimization

The project is divided into four progressive stages.

# 📊 Datasets

Different datasets were used throughout the four-week project depending on the analytical objective.

### Week 1 & Week 2

The project uses the **Brazilian E-Commerce Public Dataset by Olist**, a publicly available dataset containing information related to e-commerce orders, customers, products, payments, reviews and logistics-related operations.

The dataset provides a realistic environment for practicing logistics and e-commerce analytics.

### Week 3 & Week 4

Synthetic / hypothetical logistics datasets were used for the advanced analytics and predictive modeling stages.

These datasets are intended for **educational and analytical demonstration purposes**.

> **Important:** Results generated from synthetic datasets should not be interpreted as actual operational performance or real-world logistics benchmarks.

# 🚀 Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/jagdish-sutar/logistics_data_analysis.git
cd logistics_data_analysis
```

## 2. Create a virtual environment

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

## 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the relevant weekly folder and run the notebooks sequentially.
